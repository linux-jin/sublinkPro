# 智能分组

[English](smart-groups.md)

智能分组是**独立的动态节点集合**，不会替换原分组，也不会修改节点的 `Group`。同一节点可以同时属于多个智能分组。筛选依据是节点已保存的**落地国家**（`LinkCountry`），支持 `GB,FR,DE` 等两位国家代码，跨越所有原始分组。

## 使用方法

1. 在**订阅 → 智能分组**创建分组，选择国家、最大延迟、最低速度和结果有效期（默认 72 小时）。数值阈值为 0 表示不设该上限/下限；有效期为 0 表示不检查过期。
2. 选择已有**节点检测策略**并点击**检测候选节点**，异步检测目标国家的全部节点，包括失败或未测节点。策略应同时产生延迟与下载速度结果；只有延迟结果、没有成功速度结果的节点不会入组。任务完成后刷新成员列表。
3. 节点的延迟、速度必须**均为成功且大于零**，符合阈值，并且两项检测时间均在有效期内（有效期设为 0 时除外）。每次查询动态计算成员，失败或过期节点会自动退出。
4. 在订阅的**动态**或**混合**模式选择智能分组。生成订阅时实时取得当前成员，然后执行原有过滤与按有效名称去重。直接节点、原分组和机场排在智能分组成员之前；预览使用相同的成员条件。

被订阅引用的智能分组不能删除，须先在订阅中移除。智能分组本身不新增定时任务：可手动检测，或使用既有节点检测定时策略持续刷新结果（全节点定时检测同样覆盖这些国家）。手动选择的检测策略只提供检测参数，不限制到策略保存的分组或标签范围。

成员接口返回全部成员 ID 和前 100 个节点的展示样本；不会实际创建或移动节点原分组。
